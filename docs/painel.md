# Painel

Entre por `/login` ou crie a conta em `/cadastro`. Não há site institucional: a raiz manda para o painel ou para o login.

| Tela | Para que serve |
| --- | --- |
| Início | Cota, empresas e notas recentes |
| Notas | Filtro por estado e busca. A lista se atualiza sozinha enquanto houver fila |
| Nova NFS-e | Formulário, cenário forçado e grupos de estudo recolhidos |
| Detalhe | Linha do tempo, PDF, XML e pedido de cancelamento |
| Empresas | Cadastro, série, número, certificado, logo e desativação |
| Chaves | Gerar e revogar chave de projeto ou token de organização |
| Webhooks | URL, eventos, teste e histórico de entregas |
| Logs | Método, caminho, status e prefixo da chave |
| Caixa de saída | E-mails que não foram enviados |
| Simulação | Atraso, taxa de falha e esperas de retry |
| Uso | Créditos do plano Estudo e domínio https com verificação simulada |

O domínio de arquivos não dispara consulta DNS. O botão "Simular verificação" só muda o status para `verified`.

A faixa vermelha no topo permanece em todas as telas: este servidor não fala com órgão público.
